# Syawir - XI Bahasa Arab Tindak Lanjut MAN 4 Aceh Besar (الصحة والرعاية الصحية)

Aplikasi Web Media Pembelajaran Bahasa Arab Interaktif untuk **XI Bahasa Arab Tindak Lanjut MAN 4 Aceh Besar** pada Bab **الصحة والرعاية الصحية** (Kesehatan dan Perawatan Kesehatan) yang dikembangkan oleh **Erliana, S.Pd.I** berdasarkan **Kurikulum Berbasis Cinta (Kemenag Terbaru)**.

**Pemilik Web & Guru Pengampu**: Erliana, S.Pd.I (MAN 4 Aceh Besar)

---

## 🌟 Fitur Utama

- **📚 Mufrodat & Af'al Interaktif**: 17 kartu kosakata/ungkapan 3D flip card interaktif dengan contoh kalimat murni Bahasa Arab serta tabel 8 kata kerja (*Fi'il Madhi, Mudhari', Masdar*).
- **🎧 Maharah Istima' (Mendengar)**: Teks materi inti buku paket dan percakapan dokter-pasien (*في العيادة*) dilengkapi kontrol kecepatan audio TTS (`ar-SA`).
- **📜 Maharah Qiroah (Membaca)**: Teks bacaan *الحياة الصحية* berharakat presisi bagian (أ), (ب), dan (ج) dengan latihan soal Benar/Salah (`صحيح` / `خطأ`) dan Tanya Jawab Pemahaman.
- **✍️ Latihan Soal (Kuis 10 Soal Pilihan Ganda)**: 10 soal Pilihan Ganda dari lembar latihan resmi buku paket Kemenag terbaru dengan audio lafal soal dan kartu skor apresiasi afektif (*Mumtaz*, *Jayyid Jiddan*, *La Tahzan*).
- **💚 Refleksi Cinta (Habit Tracker)**: Jurnal harian kebiasaan sehat dan dzikir untuk menguatkan nilai kesyukuran.

## 🚀 Cara Menjalankan Project

1. Clone repositori ini:
   ```bash
   git clone https://github.com/afifmashum61-oss/Syawir.git
   cd Syawir
   ```

2. Jalankan server lokal Node.js:
   ```bash
   node server.js
   ```

3. Buka browser dan akses:
   ```
   http://localhost:8000
   ```

- **Node.js** (HTTP Server)
